# Story 1.2: Frontend Navigation Shell

Status: done

## Story

As a user,
I want a persistent navigation structure to access the Clientes and Contactos sections of the application,
so that I can move between sections without full page reloads from any device.

## Acceptance Criteria

1. **AC1 — Desktop NavigationRail**: When the app is loaded on a desktop browser (≥1024px), a `NavigationRail` (siesa-ui-kit) is visible on the left side showing "Clientes" and "Contactos" entries. Clicking either entry navigates to `/clientes` or `/contactos` without a full page reload.

2. **AC2 — Mobile NavigationBar**: When the app is loaded on a mobile viewport (<1024px), a `NavigationBar` (siesa-ui-kit) is displayed at the bottom instead of the rail. All navigation items are visible, accessible, and tappable.

3. **AC3 — Deep Linking**: Typing `/clientes` or `/contactos` directly in the browser URL bar renders the correct placeholder view without redirection to a home screen. The active nav item is visually highlighted.

4. **AC4 — Root Redirect**: Navigating to `/` automatically redirects to `/clientes` without leaving a history entry (replace: true).

5. **AC5 — 404 Not Found**: Navigating to an unknown route (e.g., `/desconocido`) renders a graceful not-found view in Spanish with a link to return to `/clientes`.

6. **AC6 — RouterProvider & QueryClientProvider**: `main.tsx` uses `RouterProvider` (TanStack Router) and `QueryClientProvider` (TanStack Query) — the `<App />` component from Story 1.1 is replaced entirely.

### Router Bootstrap Pattern

```typescript
// src/app/providers/queryClient.ts
import { QueryClient } from '@tanstack/react-query'
export const queryClient = new QueryClient({
  defaultOptions: { queries: { staleTime: 5 * 60 * 1000 } }
})

// src/router.ts — AFTER routeTree.gen.ts is generated
import { createRouter } from '@tanstack/react-router'
import { routeTree } from './routeTree.gen'
export const router = createRouter({ routeTree })
declare module '@tanstack/react-router' {
  interface Register { router: typeof router }
}

// src/main.tsx
import { RouterProvider } from '@tanstack/react-router'
import { QueryClientProvider } from '@tanstack/react-query'
import { router } from './router'
import { queryClient } from './app/providers/queryClient'
import 'siesa-ui-kit/styles.css'
ReactDOM.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <QueryClientProvider client={queryClient}>
      <RouterProvider router={router} />
    </QueryClientProvider>
  </React.StrictMode>
)
```

### Root Route Pattern (`__root.tsx`)

```typescript
import { createRootRoute, Outlet, useRouterState } from '@tanstack/react-router'
import { LayoutBase } from 'siesa-ui-kit'
import { UsersIcon, UserIcon } from '@heroicons/react/24/outline'
import { NotFoundView } from '@/shared/components/NotFoundView'

function RootComponent() {
  const routerState = useRouterState()
  const currentPath = routerState.location.pathname

  const navigationItems = [
    {
      id: 'clientes',
      label: 'Clientes',
      icon: <UsersIcon className="w-5 h-5" />,
      active: currentPath.startsWith('/clientes'),
      onClick: () => router.navigate({ to: '/clientes' }),
    },
    {
      id: 'contactos',
      label: 'Contactos',
      icon: <UserIcon className="w-5 h-5" />,
      active: currentPath.startsWith('/contactos'),
      onClick: () => router.navigate({ to: '/contactos' }),
    },
  ]

  return (
    <LayoutBase
      productName="Siesa Agents"
      navigationItems={navigationItems}
    >
      <Outlet />
    </LayoutBase>
  )
}

export const Route = createRootRoute({
  component: RootComponent,
  notFoundComponent: NotFoundView,
})
```

### TanStack Router — File Naming Rules

| File | Route path | Purpose |
|---|---|---|
| `__root.tsx` | `` (root) | Root layout — wraps everything |
| `index.tsx` | `/` | Redirect to /clientes |
| `_app.tsx` | `/_app` | Named layout (underscore = layout, no URL segment) |
| `_app/clientes.tsx` | `/clientes` | Clientes placeholder |
| `_app/contactos.tsx` | `/contactos` | Contactos placeholder |

> **routeTree.gen.ts is auto-generated** — run `npm run dev` once after creating route files. Never edit it manually.

> **`_app` prefix**: In TanStack Router, a file prefixed with `_` is a layout route. Its path segment is excluded from the URL. So `_app/clientes.tsx` registers at `/clientes`, not `/_app/clientes`.

### Testing Pattern (Vitest + RTL)

```typescript
// src/routes/__tests__/navigation.test.tsx
import { render, screen } from '@testing-library/react'
import userEvent from '@testing-library/user-event'

import { routeTree } from '../../routeTree.gen'

function renderWithRouter(initialPath = '/clientes') {
  const memoryHistory = createMemoryHistory({ initialEntries: [initialPath] })

  return render(<RouterProvider router={router} />)
}
```
